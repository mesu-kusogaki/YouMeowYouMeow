# 🐈 유묘 탐정 사무소

개인용 머더 미스터리 플레이 기록 사이트.

- 18개 사건 기록
- 사건 검색
- 사건 상세 기록
- 플레이/범인/검거 통계
- 사건마다 서로 다른 18가지 시각 테마

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 배포

Streamlit Community Cloud에서 이 저장소의 `app.py`를 연결하면 됩니다.

주인공은 고양이 수인 탐정 **유묘**이며, 각 머더 미스터리는 하나의 사건 파일로 표현합니다.
